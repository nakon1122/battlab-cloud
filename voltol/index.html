    VOLTOL / FIRMWARE

    เฟิร์มแวร์ ESP32-S3

    ติดตั้งผ่าน USB บนเว็บ

    สำหรับติดตั้งใหม่บน ESP32-S3 DevKitC-1 แฟลช 8 MB ใช้ Chrome หรือ Edge บนคอมพิวเตอร์

    เปิดเครื่องมือแฟลชผ่านเว็บ

    อัปเดตผ่าน OTA

    ดาวน์โหลดเฟิร์มแวร์ Gemini สำหรับ ESP32-S3 ผ่าน USB
    บิลด์ Gemini รายงานเวอร์ชัน 1.6.6 บอร์ด VOLTOL เดิมให้ใช้ UPDATE_S3_WINDOWS.bat เพื่อเก็บ Wi-Fi และโทเคน

    ดาวน์โหลด VOLTOL v1.6.6 รุ่นเดิม สำหรับอัปเดตผ่าน USB หรือใช้เมนู Firmware บน หน้าโมดูล

    เปิดเว็บตั้งค่าโมดูล ดูเวอร์ชันล่าสุด

    VOLTOL / TUNE

    จูนพารามิเตอร์คอนโทรลเลอร์

    เชื่อม Wi-Fi ของโมดูล เปิดหน้า ESP32 แล้วเลือก TUNE เพื่ออ่านค่า สำรอง กู้คืน และเขียนค่าผ่าน UART

    เปิดหน้าจูนบนโมดูล

    การอ่านและเขียนพารามิเตอร์จาก Cloud ยังต้องใช้เฟิร์มแวร์และช่องทางคำสั่งที่รองรับ

    เชื่อมโมดูลผ่าน Bluetooth

    เปิดโมดูลที่ยังไม่ได้ผูกบัญชี ระบบจะเปิดโหมดจับคู่อัตโนมัติ 3 นาที กดค้นหา Bluetooth แล้วเลือก VOLTOL Setup

    ถ้าโมดูลเคยผูกบัญชี ให้เปิดเมนู Bluetooth บน หน้าโมดูล แล้วใช้ลิงก์จับคู่ที่สร้างจากบอร์ด

    ตั้งค่าผ่าน USB Serial
